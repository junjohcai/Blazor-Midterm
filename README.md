# Blazor Web App with Tailwind CSS

### Prerequisites
Before running this project, ensure you have the following installed:
1. **.NET 8 SDK** (or later)
2. **Node.js** (Required to compile the Tailwind CSS)

### Install .NET 8 SDK

1. Visit the official .NET download page at [dotnet.microsoft.com/download](https://www.google.com/search?q=https%3A%2F%2Fdotnet.microsoft.com%2Fdownload).
2. Select **.NET 8**, which is the stable Long Term Support (LTS) version.
3. Download the correct installer for your operating system (e.g., the `.exe` file for Windows or `.pkg` for macOS).
4. Run the installer and accept all default settings.
5. Verify the installation by opening a new Command Prompt or Terminal and running the command `dotnet --version`.

### Install Node.js

1. Visit the official Node.js website. https://nodejs.org/en/download
2. Download the **LTS (Long Term Support)** installer for your operating system. The LTS version is recommended for its stability. Find the **[Windows Installer (.msi)]** button.
3. Run the downloaded installer (such as the `.msi` file on Windows).
4. Follow the setup wizard, accept the license agreement, and leave the default installation settings as they are.
5. Verify the installation by opening a new Command Prompt or Terminal and running `node -v` and `npm -v`. Both commands will return version numbers if the installation was successful.
